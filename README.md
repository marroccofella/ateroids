# @TEROIDS — Arcade Word & Number Shooter

> `RELAX. IT'S ALREADY OVER.`
>
> A rogue application from **[The Library](https://42.uk)** — an unstable collection of
> anomalous software generated by the very chaos we're navigating.

Classic asteroids physics, except the rocks carry **letters and numbers**. Shoot them
loose, rack up word scores, and deploy the smart bomb when the ambient field gets
too loud. No guarantees. Only opportunity.

## Controls

| Input | Action |
| --- | --- |
| `←` `→` | Rotate ship |
| `↑` | Thrust |
| `Space` | Shoot |
| `B` | Smart bomb |

Touch controls appear automatically on mobile. Mute toggle in the HUD.

## Run it

No build step. It's one canvas, one script, zero excuses:

```bash
# any static server works
npx serve .
```

Then open `http://localhost:3000`.

## Stack

- Vanilla JavaScript + `<canvas>` — the whole game lives in `game.js`
- Leftover Firestore config is locked down (`allow read, write: if false`); nothing
  server-side ships until a leaderboard actually does
