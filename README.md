Classic asteroid physics with collectible letters. Shoot rocks to release letters,
collect them with your ship for word scores, and deploy a smart bomb when the field
gets too crowded.

## Controls

| Input | Action |
| --- | --- |
| `←` `→` | Rotate ship |
| `↑` | Thrust |
| `Space` | Shoot |
| `B` | Smart bomb |

Touch controls appear automatically on mobile. Mute toggle in the HUD.

## Run it

No build step. It's one canvas, one script, zero excuses:

```bash
# any static server works
npx serve .
```

Then open `http://localhost:3000`.

## Stack

- Vanilla JavaScript + `<canvas>` — the whole game lives in `game.js`
- Leftover Firestore config is locked down (`allow read, write: if false`); nothing
  server-side ships until a leaderboard actually does
